      Function reference

      WriteWhat it does
      sin(x) cos(x) tan(x)Trig on an angle parameter or an angle like 30°
      asin(x) acos(x) atan(x)Inverse trig on a plain ratio. Returns an angle.
      sqrt(x)Square root. An area in gives a length out.
      x ^ yPower, so R ^ 2 is an area
      pi()3.14159…
      abs(x)Absolute value
      exp(x) ln(x) log(x)e to the x, natural log, base-10 log
      round(x) roundup(x) rounddown(x)Rounding. Use on a plain ratio like W / M.
      if(test, a, b)Conditional. Combine tests with and(), or(), not().
      < > =The only comparisons. There is no >= or <=.
